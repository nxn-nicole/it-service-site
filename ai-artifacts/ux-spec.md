# 1) UX Goals (English allowed)
- Make the first screen instantly clarify “who this is for” and “what happens next” (low-pressure, action-oriented).
- Increase trust via specific, scannable proof (student stories with background → problem → process → benefit).
- Keep conversion friction low: persistent CTAs, one primary action, one secondary action per page.
- Optimize for scanability for mixed English levels: short paragraphs, bullets, clear hierarchy, predictable patterns.
- Mobile-first readability: generous spacing, strong typographic rhythm, clear tappable targets.
- Avoid overpromising: reinforce process/support, set realistic expectations, and communicate scope boundaries.

# 2) IA + Navigation
- Final nav labels (Chinese, user-visible): 首页｜服务｜学员评价｜联系
- Notes (English):
  - Mirrors the required core structure (Intro → Services → Reviews) with an optional but always-available Contact endpoint.
  - Labels are short, high-recognition Chinese terms for fast scanning on mobile.
  - “联系” supports CTAs across pages without forcing users to “go back” to find a next step.
